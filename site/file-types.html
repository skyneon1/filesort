How the ending is read

The ending (also called the extension) is the part of the file name after the last dot. Upper and lower case make no difference: photo.JPG and photo.jpg both go to Images.

Only the last ending counts. backup.tar.gz ends in gz, so it goes to Archives.

FileSort looks at the name only. It does not open files to check what is really inside them.

Sorting by extension instead

If you sort by extension, the table above is not used. Each ending gets its own folder, named in lower case: jpg, pdf, zip. Files without an ending go into a folder called no_extension.

Sorting by month

The kind of file does not matter here. Each file goes into a folder named after the year and month it was last changed, for example 2026-11.
