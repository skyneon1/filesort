How to sort files into folders automatically

Moving hundreds of files into folders by hand takes an afternoon. This is how to do it in about a minute, on Windows, Mac or Linux, without installing a program.

What your computer can and cannot do by itself

File Explorer on Windows and Finder on a Mac can group files by type or date, but that only changes the view. The files all stay loose in the same folder. To put each file into a folder of its own kind you either drag them yourself, write a script, or use a tool.

The quick way: FileSort

FileSort is a free web page that sorts the files in a folder into subfolders. It runs in your browser, so nothing is uploaded and there is nothing to install.

  1. Open FileSort and click Select folder.
  2. Pick the folder with the loose files and allow access when the browser asks.
  3. Choose the rule: File type, Extension or Month.
  4. Look through the list. It shows every folder that will be made and which files go into it.
  5. Press Sort files.

Is it safe?

  • You see the plan first. Nothing moves until you press the button.
  • Nothing is overwritten. If two files have the same name, the second becomes "name (1)".
  • It can be undone. Undo last sort puts every file back where it was.
  • Subfolders are left alone unless you switch on "Include subfolders". Programs and code projects are never taken apart.

Which browsers work

Chrome and Edge on a computer sort the folder itself. Firefox, Safari and phones cannot change files on disk, so there FileSort gives you a sorted copy of the folder as a .zip file to download instead.

Common questions

Can I sort files in subfolders too?

Yes. Switch on "Include subfolders" and files inside subfolders are pulled out and sorted as well.

Does it work with thousands of files?

Yes. A few thousand files take seconds in Chrome or Edge, because the files are moved rather than copied.
