Before you start

FileSort takes the loose files in one folder and puts each of them into a subfolder. A folder with 300 mixed files becomes a folder with a handful of subfolders such as Images, Documents and Videos.

It only moves files. It does not delete, rename, compress or upload them. The one exception to "does not rename" is when two files with the same name would land in the same folder; see step 4.

If you want to see it work first, click "Try it with sample files first" on the start page. That uses made-up example files, not yours.

1. Select the folder

Click Select folder and choose the folder you want to tidy. What happens next depends on your browser.

Chrome and Edge

The browser asks whether the site may view the files, and then whether it may save changes to the folder. Allow both. FileSort can then see that one folder and nothing else on your computer.

Chrome and Edge refuse to open a few system folders directly, including Downloads, Documents and Desktop. See Tips for the way around this.

Firefox and Safari

The browser shows a question such as "Upload 240 files to this site?". The wording is the browser's, not ours. Nothing is uploaded: the files are only read on your computer. Choose Upload to continue.

Phones and tablets

Phones cannot select a folder, so the button says Select files. Pick the files you want sorted.

2. Choose how to sort

There are three ways to sort. You can switch between them freely; the list below updates each time and nothing moves until you press the sort button.

The full list of which ending goes into which folder is on the File types page.

Month uses the date the file was last changed, not the date it was created or downloaded.

3. Set the options

Include subfolders

Off: only the files lying directly in the folder are sorted. Folders inside it are left exactly as they are. This is the safe default.

On: files inside subfolders are taken out and sorted too. Programs and projects are never taken apart: app bundles, code repositories and folders such as node_modules are skipped as a whole.

Include hidden files

Hidden files are files whose name starts with a dot, such as .gitignore. They are skipped unless you switch this on. Most people should leave it off.

Delete emptied folders

Only available together with Include subfolders, and only in Chrome and Edge. After sorting, subfolders that are now empty are removed. Folders that were already empty before, or that still contain anything, are kept.

4. Check the list

You now see every folder that will be created and how many files go into it. Click a folder to see the files.

If a file is shown as "renamed to report (1).pdf", another file called report.pdf is already going to that folder. FileSort never overwrites a file, so the second one gets a number.

Files that are missing from the list are files FileSort leaves alone. The reasons are listed on the Help page.

5. Sort

Chrome and Edge

Press Sort files and confirm. The files are moved on your disk straight away. A folder with a few hundred files takes a second or two.

Firefox, Safari and phones

These browsers do not allow a website to change files on your disk. Press Download sorted copy and you get a .zip file containing a sorted copy of the folder. Unpack it where you want it. Your original folder is not changed, so you can delete it yourself once you are happy with the copy.

The copy can be at most 3.5 GB or 60,000 files.

Undo

In Chrome and Edge, press Undo last sort to put every file back where it was. This also works later: open the same folder again and the button is there.

Undo relies on a small hidden file, .filesort-undo.json, that FileSort saves in the folder. If you delete it, that sort can no longer be undone.

If you created a new file with the same name in the old place in the meantime, undo leaves that one file where it is instead of overwriting yours, and tells you.

In Firefox and Safari there is nothing to undo, because the original folder is never changed.

Tips

Sorting your Downloads folder in Chrome or Edge

Make a new folder inside Downloads, for example "To sort". Move the files into it, then select that folder in FileSort.

Sorting again later

You can run FileSort on the same folder as often as you like. Files that are already in the right subfolder stay there; only new loose files are moved.

Important files

Sorting is reversible, but keep a backup of files you cannot afford to lose, as you should anyway.
