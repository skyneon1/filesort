How to start it

Windows

Open the downloaded file. If a blue "Windows protected your PC" window appears, click More info, then Run anyway.

Mac

Open the .zip, then right-click the app and choose Open. Confirm with Open. This is only needed the first time.

Linux

1. Right-click the downloaded file and choose Extract Here.
2. Open the new folder, right-click FileSort and choose Run as a Program. On some systems a double-click also works.

If you see "There is no app installed for Executable files", the file is not allowed to run yet: right-click FileSort, choose Properties, and switch on "Executable as Program". Or in a terminal: chmod +x FileSort, then ./FileSort.

Windows and Mac show a warning on first start because the app is free and not signed with a paid developer certificate.
