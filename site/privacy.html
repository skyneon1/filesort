Privacy

WhatCollected?

CookiesNo

Server logs (IP address, time of visit)Possibly, by the company hosting this website

How the website handles your files

When you select a folder, your browser asks you to allow access to it. The website can then read and move files in that one folder only. All of this happens inside your browser. There is no server that receives files, file names or anything about them.

In Firefox, Safari and on phones, the website reads the folder you select and builds a sorted copy as a .zip file on your own device. Your browser may call this step an "upload", but nothing leaves your computer.

Access ends when you close the tab. The next time you visit, you have to select the folder again.

The desktop app

The app does not connect to the internet. It reads and moves files only in the folder you choose.

The one file we create

After sorting, a small hidden file named .filesort-undo.json is saved in the folder you sorted. It lists which files were moved and from where, so that Undo can put them back. It stays on your computer. You can delete it at any time; you then lose Undo for that folder.

Sample files

"Try it with sample files" creates a few empty example files in a private storage area of your browser. They are not on your disk in any folder you can see and contain no data of yours.
