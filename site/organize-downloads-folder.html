How to organize your Downloads folder

Downloads is the folder that fills up by itself. Here is the quickest way to clean it up on Windows or Mac, and how to keep it from getting messy again.

Why the Downloads folder gets messy

Everything lands there: invoices, installers, photos, zip files, PDFs you opened once. Nothing is ever filed, so after a few months it holds hundreds of unrelated files and finding one means scrolling or searching.

Step 1: Delete what you do not need

Sort the folder by size or date first, because the biggest and oldest files are the easiest to judge.

  • Windows: open Downloads, right-click an empty area, choose Sort by, then Size or Date modified.
  • Mac: open Downloads in Finder, choose View, then as List, and click the Size or Date Added column.

Installers (.exe, .msi, .dmg) can almost always go once the program is installed. So can zip files you have already unpacked.

Step 2: Sort what is left into folders

Windows and Mac can group files on screen, but they do not move them into folders for you. To actually file them, use FileSort. It is free and runs in your browser, and your files are not uploaded anywhere.

  1. In Downloads, make a new folder called To sort and move the loose files into it. (Chrome and Edge do not let a website open the Downloads folder itself, but a folder inside it is fine.)
  2. Open FileSort and click Select folder. Choose the To sort folder.
  3. Choose how to sort: by file type (Images, Documents, Videos and so on), by extension, or by month.
  4. Check the list of what will go where, then press Sort files.

You end up with a handful of folders such as Images, Documents, Archives and Installers. If you do not like the result, Undo puts every file back.

Step 3: Keep it organized

  • Sort again once a month. Files that are already in the right folder stay there; only new loose files are moved.
  • Move keepers out. Downloads is a waiting room. Documents you want to keep belong in Documents, photos in Pictures.
  • Let the system delete old files. On Windows, Storage Sense (Settings, System, Storage) can remove files in Downloads that have not been opened for a set time. On a Mac, check the storage recommendations under System Settings, General, Storage.

Common questions

Is there a way to organize downloads into folders automatically?

Not built in. Windows and macOS only change how the files are displayed. A tool like FileSort does the moving, and you can rerun it whenever the folder fills up.

Should I sort by type or by date?

By type suits most Downloads folders, because you usually remember what a file was. By month suits folders full of similar things, such as scans or statements.
