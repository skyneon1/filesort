How to organize files by date into folders

Sorting by date is the simplest way to file things you think of in terms of "when": scans, statements, invoices, exports, photos. This is how to put files into one folder per month automatically.

Sorting by date versus organizing by date

Every file manager can sort a folder by date: click the Date modified column on Windows or the Date Modified column in Finder. That changes the order of the list. It does not put the files into dated folders. For that you need to move them.

Put files into monthly folders with FileSort

  1. Open FileSort and click Select folder.
  2. Choose the folder you want to organize.
  3. Under Sort by, choose Month.
  4. Check the list, then press Sort files.

Each file goes into a folder named with the year and month, for example 2026-11, 2026-10, 2026-09. Because the year comes first, the folders line up in time order by themselves.

Which date is used

FileSort uses the date the file was last modified. For most downloaded, scanned or exported files that is the day you got them. Two things to know:

  • If you edited a file later, it is filed under the month of the edit.
  • Files copied from another disk usually keep their original date, but some copy methods reset it to today.

If you are unsure, look at the list before you press Sort. It shows the folder each file will go into.

Good uses

  • Bank statements and invoices that arrive every month.
  • Scanned documents that all have names like scan0042.pdf.
  • Screenshots, which pile up fast and are easiest to find by when you took them.
  • Photos from a camera or phone; see sorting photos by date.

Common questions

Can I sort by year instead of month?

Not directly. Folders are per month, and since each name starts with the year, all of 2026 sits together in the list.

Can I undo it?

Yes, in Chrome and Edge. Open the same folder again and press Undo last sort.
