How it works

  1. Select a folder

    Pick the folder you want to clean up, for example a folder full of downloads.

    You see which files will go into which folder. Nothing has moved at this point.

  3. Sort

    Press Sort files. If you do not like the result, Undo puts everything back.

Questions

Are my files uploaded anywhere?

No. The sorting is done by your browser on your own disk. This site has no server that could receive files. More on the privacy page.

What do the three sorting options do?

File type makes folders such as Images, Documents and Videos. Extension makes one folder per extension, such as jpg, pdf and zip. Month makes folders such as 2026-11, based on when each file was last changed.

What does "Include subfolders" do?

Normally only the files directly in the folder are sorted and subfolders are left alone. With this option, files inside subfolders are sorted too. Programs and projects are never taken apart: app bundles, code repositories and folders such as node_modules are skipped.

What if two files have the same name?

Nothing is ever overwritten. The second file is renamed, for example report (1).pdf.

Can I undo it?

Yes. Open the same folder again and press Undo last sort. To make this possible, a small hidden file named .filesort-undo.json is kept in the folder.

Which browsers does it work in?

Chrome and Edge on Windows, Mac and Linux. Firefox, Safari and phones cannot give a website access to a folder. For those, use the desktop app.

Why can I not select my Downloads or Documents folder?

Chrome and Edge block websites from opening some system folders directly. Select a folder inside it instead, or use the desktop app, which has no such limit.
